# Module Web Dashboard (Phụ trách: Lưu Thị Kim Liên)

## Hướng dẫn cho Liên:
1. Đặt file `index.html` bảng điều khiển của Liên vào thư mục `src/EduGuard.Dashboard/` này.
2. Backend C# đã mở CORS sẵn tại cổng `http://localhost:5160`.
3. Sử dụng hàm `fetchClassroomState()` trong `api_connector.js` để tự động cập nhật sơ đồ bàn học và biểu đồ CEI!
